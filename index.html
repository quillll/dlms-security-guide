DLMS/COSEM 安全套件 · 课程

这门课为什么存在：你在实现/对接 DLMS 客户端与服务端，需要读懂绿皮书/蓝皮书的原文条款，并把它们落到可运行的代码与可核对的报文上。 课程据此排列：先把坐标系立住（套件 vs 策略 vs 材料），再下沉到字节。
完整目标与边界见 MISSION.md。

课程（按顺序做）

第 1 课 · Suite 0/1/2：先把三个旋钮分清

安全套件 ≠ 安全等级。读懂 Table 27，学会只看一个字节就说出"套件 + 保护方式"。含可点的 SC 字节解码器与 4 道检索练习。约 12 分钟。

第 2 课 · 报文一级：把规范印的字节拆开，再自己算一遍

Tag ‖ Len ‖ SH ‖ 内容 ‖ tag：读懂 Table 48 的三条真实报文，Len 的算法，P/AAD/IV 怎么拼；含可粘贴 hex 的报文拆分器与能对拍规范答案的 Python 脚本。约 18 分钟。

第 3 课 · general-* 家族：报文里怎么"顺便"带上一把密钥

两层结构（外层寄件信息 + 内层 SH‖内容‖tag）、key-info 的三种 CHOICE、三种密钥协商方案与规范默认选择；含能拆 general-* 的拆分器与 4 组新的对拍向量。约 16 分钟。

第 4 课 · association 认证：三个等级、四趟 HLS，与能算出来的 GMAC

建链时怎么认身份。三种认证等级的对照、四趟 HLS 各自装在哪条报文、Table 50 的七种 mechanism（含为何不推荐 MD5/SHA-1），以及 Table 51 两条 GMAC 向量的实测对拍。约 18 分钟。

第 5 课 · 密钥全貌：六把对称密钥从哪来，KEK 为什么要"自己包自己"

EK / AK / KEK / GUEK / GBEK / GAK 一次理清（Table 28）、三条建立路径（带外 / 包装 / 协商）、key_transfer 的参数结构，以及 KEK 轮换为什么要"用旧 KEK 包新 KEK、成功后立即生效"。约 17 分钟。

第 6 课 · Security setup 实操：读哪几个属性，调哪几个方法

把前五课落到设备对象上。OBIS 与"一个 AA 一个"、属性 2 security_policy 位图与属性 3 security_suite 枚举、方法 1–8，以及 security_activate 为何只能加强不能削弱。含对接新设备的排障清单。约 16 分钟。

参考文档（回头查，不用顺序读）

Suite 0/1/2 速查表

Table 27 逐字对照、EK/KEK/tag/IV 尺寸、SC 字节位图、P/AAD 规则、套件与计数器对象配在哪里，以及四个最常见的混淆点。打印友好。

密码学最小必要直觉

AES-GCM、AES key wrap、ECDH、ECDSA、SHA 各一段直觉 + "在 DLMS 里做什么" + 权威来源。只为读懂套件表而写。

对拍脚本 · verify-dlms-gcm.py

用普通 AES-GCM 原语复现规范印着的字节：Table 48 的三条报文、Annex C.1 的 KDF、C.2/C.3 四个方向的派生密钥，以及 Table 51 的两条 HLS GMAC 认证值——共 10 组，全部自动比对。改几个常量就能验你自己的实现。

怎么用这门课

  1. 每课只做一件事，10–15 分钟能做完。做不完就停，下次继续——课程不追求覆盖面，追求"能取用"。
  2. 先读一手来源再做题。每课都给出绿皮书的具体章节与页码；遇到与课程叙述不一致时，以规范为准，并告诉我，我会改。
  3. 测验要闭卷。答错比答对有价值：它标出了你下一次会踩的坑。
  4. 卡住立刻问。每课末尾都有入口；你可以直接把一段 hex 报文、一段配置或一段代码贴给我，我们逐字段过。
